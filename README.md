# CinemaApp

Фронтенд прилоежние для просмотра расписания сеансов, каталога фильмов, событий и регистрации пользователей.

## Технологический стек

* **Frontend:** React, TypeScript, Vite
* **Стили:** SCSS Modules
* **Архитектура:** Feature-Sliced Design (FSD)
* **База данных:** Mock-сервер эмулирующий полноценную базу данных

---

## Установка и запуск

Для запуска проекта локально требуется [Node.js](https://nodejs.org/en) и `npm` (или `pnpm`).

### Клонирование репозитория
```bash
git clone https://github.com/vikik228/CinemaApp
cd CinemaApp
```

### Установка зависимостей
```bash
npm install 
```

### Запуск сервера и приложения
```bash
npm run dev
```

---

## Структура проекта

Код собран по архитектуре FSD:

* `src/app/` - инициализация приложения, глобальные стили, провайдеры.
* `src/pages/` - страницы приложения (Главная, каталог, события).
* `src/widgets/` - блоки страниц (Навигационное меню (NavBar), сетка фильмов).
* `src/features/` - действия пользователя (Покупка билетов, фильтрация по жанрам).
* `src/entities/` - бизнес-сущности (Фильм, сеанс).
* `src/shared/` - переиспользуемый код (UI компоненты, API-клиент, Mock-данные).
